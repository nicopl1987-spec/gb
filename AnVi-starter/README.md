# AnVi — офлайн-библиотека вайшнавских писаний

## Как получить APK (бесплатно, через GitHub Actions)

1. Создайте репозиторий на GitHub (публичный — артефакты бесплатны).
2. Загрузите содержимое этой папки в корень репозитория.
3. Включите Actions (Settings → Actions → General → Allow all actions).
4. Запустите workflow `Build AnVi APK` вручную (Actions → Build AnVi APK → Run workflow)
   или сделайте push. Сборка занимает 10–15 минут.
5. В открывшемся запуске workflow внизу будет артефакт `anvi-debug-apk`
   с файлом `app-debug.apk`. Debug-APK уже подписан debug-ключом и ставится на телефон
   как обычный APK (разрешить «установку из неизвестных источников»).

## Локальная сборка (при наличии Android Studio)

Откройте папку в Android Studio, дождитесь синхронизации Gradle,
Build → Build Bundle(s) / APK(s) → Build APK(s).

## Правовая оговорка о текстах

Переводы Бхактиведанты Свами Прабхупады (Bhagavad-gita As It Is, Шримад-Бхагаватам,
Чайтанья-чаритамрита, Нектар преданности и др.) являются объектом авторских прав BBT.
Для их распространения в приложении необходимо разрешение BBT. Без него используйте
тексты в общественном достоянии (например, ранние переводы Bhagavata Purana,
Gita с санскритским оригиналом и синонимами вне авторских прав, тексты с vanisource.org
проверяйте на условия лицензии отдельно).
